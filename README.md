# Azeroth Atlas

[Open Azeroth Atlas](https://rootcastleco.github.io/azeroth-atlas/)

Bilingual World of Warcraft item and NPC atlas. Static HTML, CSS and JavaScript; no build step.

Features include expansion selection, item type and quality filters, equipment slot and item level filters, sorting, favorites, ID copying and shareable item links. Mobile layouts use filter and detail panels.

## Deploy

GitHub Pages serves `main` from `/ (root)`. `.nojekyll` preserves the static files. Relative asset paths support the `/azeroth-atlas/` project URL.

## Coverage

The site retains the imported item records through Midnight and name-grouped retail NPC IDs. Item names and game text remain in English. Icon coverage is incomplete; complete spell and mount databases are not included. Retail statistics reflect the supplied current retail dataset rather than the original expansion patch.

The imported item dataset license is preserved in `data/ItemDB-LICENSE.txt`. World of Warcraft is a trademark of Blizzard Entertainment. This is an independent fan project.
